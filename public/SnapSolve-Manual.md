# SnapSolve उपयोग-पुस्तिका

## 1. Doubt पूछें
New doubt खोलें, प्रश्न लिखें, फिर ऊपर वाले तीर से भेजें। Photo / PDF या Snap / upload से फोटो, PDF या .pptx जोड़ें। Chat upload: प्रति file 15 MB, अधिकतम 4 files। Text वाले PDF/PPTX से पढ़ने योग्य text निकाला जाता है; scanned PDF, diagrams और slide images का पूरा text मिलना सुनिश्चित नहीं है। पुरानी .ppt को .pptx/PDF में बदलें।

Model और effort चुनें; अधिक effort या बड़े documents में जवाब आने का समय बढ़ सकता है। Stop response से चल रहा उत्तर रोकें। Follow-up उसी doubt में पूछें। AI जवाब जाँचें; उसे NCERT या official answer key का विकल्प न मानें।

## 2. Settings और keyboard
Sidebar के नीचे Settings खोलें। छोटे screen पर Study menu में Settings है।
- Answer labels: A/B/C/D ↔ 1/2/3/4; admin और quiz में वही device preference लागू होती है।
- Bold questions: अपने प्रश्न और current quiz/practice question को bold करें।
- Study text size: 14, 16, 18 या 20 px चुनें; प्रश्न, उत्तर और quiz option text पर लागू, menu/input controls पर नहीं।
- Hide Chat Widget: Settings या quiz में toggle करें; दोनों जगह same choice, reload पर भी बनी रहती है। केवल quiz में input छुपता है।
- Quiz timer: Admin default या This device चुनें। Device seconds 0–600; 0 = off। Device setting admin के पूरे ऐप वाले timer को नहीं बदलती। समय खत्म होने पर एक बार Skip भेजता है; grading के समय countdown रुकता है। Timer बदलने से current countdown फिर शुरू होता है, लेकिन पहले दिया answer दुबारा नहीं खुलता।
- Keyboard answers: shortcut चालू/बंद करें; शुरुआत में चालू है।
- ऊपर वाली number row और दाएँ numeric keypad दोनों पर 1→A, 2→B, 3→C, 4→D। Numeric keypad पर Num Lock बंद हो तब भी physical keys पहचानी जाती हैं।
- उत्तर देने से पहले प्रश्न या खाली जगह पर click करके typing box से focus हटाएँ। Typing, खुली Settings/dialog, Ctrl/Alt/Shift/Command, held keys या grading के समय shortcut जवाब नहीं भेजता।
- Label बदलने से grading नहीं बदलती: key 2 हमेशा B भेजती है। Answer button से click करना भी चालू रहता है।
- Settings में Backup, Restore, Clear uploaded media, manual download और Admin उपलब्ध हैं।

## 3. Quiz
Quiz चालू करके chapter/topic भेजें। उत्तर चुनें, Hint लें, Skip करें या Stop quiz दबाएँ। एक प्रश्न पर दो बार उत्तर भेजना रोका जाता है। Hide Chat Widget से input छुपाएँ; Show Chat Widget से वापस खोलें। Search quiz में बंद रहता है। Timer/default mode admin में बदलते हैं।

Grading के बाद NCERT reference में chapter → topic → subtopic → paragraph/page दिखता है। Exact page edition पर निर्भर है: verified source न हो तो “not verified for this edition” लिखा जाएगा, अनुमानित page number नहीं। Printed page और PDF page अलग होते हैं। पुराने saved answers अपने आप rewrite नहीं होते; उस doubt में source reference का follow-up माँगें।

## 4. Search और PDF links
Solve mode में Search चालू करें। Public readable PDF/page link और अपना प्रश्न भेजें। Private/blocked links का text उपलब्ध न हो तो पढ़ने का दावा स्वीकार न करें। Private Google Drive access अभी अधिकृत नहीं है। गलत या पुराने स्रोतों को official NCERT/NTA स्रोत से जाँचें।

## 5. Voice
Input के पास mic दबाएँ और browser में microphone अनुमति दें। बोलना समाप्त करके recording रोकें; transcript आने पर उसे सुधारें और फिर भेजें। Voice स्वयं प्रश्न नहीं भेजती। Voice AI credits उपयोग करती है; real phone microphone की गुणवत्ता browser/device/network पर निर्भर करती है।

## 6. Saved practice
Saved practice में उपलब्ध saved question/card खोलें। Reveal saved answer → Remembered या Needs revision चुनें। Progress इसी browser में रहता है और reload पर session जारी रहता है। यह सुविधा tutor call नहीं करती और AI credits समाप्त होने पर भी saved material से चलती है।

## 7. Backup और recovery
Regular Backup डाउनलोड करें और दूसरी सुरक्षित जगह रखें। Restore में valid study JSON चुनें: मौजूदा data रखा जाता है और import merge होता है। Clear uploaded media पुष्टि के बाद photos/PDF/extracted text हटाता है; answers/cards बचते हैं। Document वाले follow-up के लिए file दोबारा लगानी पड़ सकती है।

Browser data, admin Cloud memory और GitHub source तीन अलग backups हैं। Admin device recovery application memory/settings का backup है—accounts, originals और browser chats का पूरा backup नहीं। Cleanup से पहले backup फिर से select करके validate करें। कोई storage असीमित या हमेशा सुरक्षित नहीं है; browser data साफ करने से पहले backup अनिवार्य रखें।

## 8. Admin
Admin में अधिकृत खाते से sign in करें। PDF, notes, links, Fact, Assertion–Reason, Insight, Teacher/Mistake questions, Flashcard, Active recall, PYQ और FYQ सामग्री रखें। File/raw imports अधिकतम 25 MB; readable text अधिकतम 400,000 characters। Text-only retention default है; जरूरत हो तभी original रखें। Same content/source के duplicates skip होते हैं, लेकिन एक साथ अलग devices से imports पूरी तरह atomic नहीं हैं।

Bulk import CSV, जुड़े Google Sheets, Markdown और Anki exported text/JSON से हो सकता है; .apkg packages supported नहीं हैं। Private Drive permission उपलब्ध नहीं है। PYQ year tips केवल stored actual question और source evidence के साथ भरोसेमंद हैं; archive/reference year actual question evidence नहीं है।

## 9. समस्या आने पर
- Unknown model / configuration / 401: workspace setup की समस्या, जरूरी नहीं कि credits कम हों।
- Credits exhausted: saved practice खोलें; fake balance नहीं दिखाया जाता।
- Storage full / save failed: page खुला रखें, Backup लें और media cleanup सोच-समझकर करें; बिना backup browser data न मिटाएँ।
- File empty/unreadable: text PDF या readable public link दोबारा दें।
- Mic denied: browser microphone permission सुधारें या typed question भेजें।

## 10. Export
एक doubt में Export chat as markdown और sidebar में Export all (.md / Obsidian) इस्तेमाल करें। Export readable notes के लिए है; recovery के लिए JSON Backup अलग रखें।
